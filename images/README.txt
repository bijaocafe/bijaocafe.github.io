BijaoCafé — imágenes necesarias
================================
Guarda tus fotografías en esta carpeta (/images) usando EXACTAMENTE estos
nombres de archivo para que aparezcan automáticamente en la página.
Si prefieres otros nombres, también puedes cambiarlos en index.html
(busca cada "src=").

Recomendaciones:
- Usa fotos cuadradas (1:1) para el catálogo y la galería; se recortan
  automáticamente pero se ven mejor si ya vienen cuadradas.
- Comprime las imágenes (por ejemplo con https://squoosh.app) antes de
  subirlas, para que la página cargue rápido.
- Puedes agregar más imágenes a la galería copiando un bloque
  <div class="galeria-item aspect-square">...</div> dentro de index.html.
